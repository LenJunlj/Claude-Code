## 🚀 在 Obsidian 中使用

### 方式一：Obsidian 核心模板插件

1. 打开 Obsidian 设置 → **核心插件** → 启用 **模板**
2. 设置 → **模板文件夹路径** → 指向 `kb/templates/`
3. 在笔记中按 `Ctrl/Cmd + T` 插入模板，填入 `{{变量}}` 内容

### 方式二：Templater 插件（推荐 🔥）

1. 安装社区插件 **Templater**
2. 设置模板文件夹为 `kb/templates/`
3. 使用 `<%* %>` 语法实现更强大的功能（自动填充日期等）
4. 按 `Alt + E` 插入模板并自动替换变量

> **提示**：模板中使用 `{{variable}}` 格式作为占位符，Templater 可配置弹窗动态输入。

## 🔗 流程映射

```
测试计划  ──→  测试计划模板 + 5W1H
测试分析  ──→  测试条件模板（可追溯性）
测试设计  ──→  测试用例模板 / 汽车测试用例设计模板（🚗 车载控制器专用）
测试实施  ──→  测试规程模板（环境+分组+优先级）
测试执行  ──→  测试日志模板 + 缺陷报告模板
监督与控制 ──→  测试日报模板
测试结束  ──→  测试报告模板
```

### 汽车测试用例模板特色

[[汽车测试用例设计模板]] 专门针对车载控制器测试设计，具备以下特色：

- **功能属性分类**：阈值类/查表类/条件使能类/状态跳转类/故障类/配置类/流程类
- **设计方法标注**：关联 [[iso-29119-4|ISO 29119-4]] 测试技术和 [[csae-177-2021|T/CSAE 177]] 11类方法
- **观测信号表**：CANFD 报文信号级验证
- **ASIL 等级标注**：功能安全追溯
- **测试环境标识**：MIL/SIL/HIL/实车

> **Schema 版本**：v1.0（随使用持续进化）
