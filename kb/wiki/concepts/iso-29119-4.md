# ISO/IEC/IEEE 29119-4:2015 软件测试技术

**ISO/IEC/IEEE 29119-4:2015** 是国际软件测试标准系列的第四部分，专门定义**软件测试设计技术**（测试用例设计方法）。第一版发布于 2015-12-01，后续被 2021 版取代。

> 中文全称：《软件与系统工程 — 软件测试 — 第4部分：测试技术》
> 系列组成：Part 1（概念与定义）、Part 2（测试过程）、Part 3（测试文档）、Part 4（测试技术）、Part 5（关键字驱动测试）

---

## 三大技术分类

### 1. 基于规格说明（Specification-Based / 黑盒）
基于功能和非功能需求分析，不考察内部结构：

| 技术 | 说明 |
|------|------|
| **等价类划分** | 划分输入/输出域，每类取代表值 |
| **分类树方法** | 构建输入分类的树形模型 |
| **边界值分析** | 在等价类边界选取测试值 |
| **语法测试** | 基于输入的形式化语法模型 |
| **组合测试** | 参数组合的系统性选择（如 Pairwise） |
| **决策表测试** | 条件（因）→ 动作（果）的逻辑关系 |
| **因果图** | 决策表的图形化变体 |
| **状态迁移测试** | 基于状态、转换、事件和守卫条件建模 |
| **场景测试** | 用户交互序列（用例/用户旅程） |
| **随机测试** | 基于输入分布模型的随机选择 |

### 2. 基于结构（Structure-Based / 白盒）
基于源代码的内部结构分析：

| 技术 | 说明 |
|------|------|
| **语句测试** | 覆盖每条可执行语句 |
| **分支测试** | 覆盖每个分支结果（true/false） |
| **判定测试** | 关注判定结果 |
| **分支条件测试** | 覆盖判定内的每个条件 |
| **分支条件组合测试** | 覆盖条件的所有组合 |
| **MCDC** | 证明每个条件独立影响判定结果 |
| **数据流测试** | 追踪变量的定义和使用 |

### 3. 基于经验（Experience-Based）
基于测试人员的知识、直觉和经验：

| 技术 | 说明 |
|------|------|
| **错误猜想** | 使用缺陷检查表和错误分类法定位缺陷 |

## 覆盖度量（第6章）

标准为每种技术定义了对应的覆盖度量方法（如等价类覆盖、语句覆盖、分支覆盖），覆盖度范围 0%~100%，需考虑不可达项。
