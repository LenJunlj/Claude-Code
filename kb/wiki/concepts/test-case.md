# 测试用例

**测试用例**（Test Case）是测试设计阶段的输出产物，是对测试条件（Test Condition）的细化和具体化，描述了一组输入、执行条件和预期结果，用于验证某个特定功能或场景是否满足需求。

## 典型组成

- **用例ID**：唯一标识符（可追溯至需求）
- **测试标题**：概括测试场景
- **前置条件**：执行前需要满足的环境或数据状态
- **测试步骤**：具体的操作步骤
- **输入数据**：步骤中使用的数据
- **预期结果**：操作后的期望表现
- **实际结果**：执行后的实际表现（执行阶段填写）
- **状态**：通过/失败/阻塞/未执行

## 汽车行业扩展要素

在汽车控制器测试中，测试用例还需包含以下要素：

| 扩展要素 | 说明 |
|----------|------|
| **需求编号** | 可追溯至功能规范/软件需求 |
| **用例级别** | P0/P1/P2（优先级） |
| **功能属性** | 阈值类/查表类/条件使能类/状态跳转类/故障类/配置类/流程类 |
| **设计方法** | 标注所用的设计方法（边界值/等价类/MCDC/状态转换等） |
| **ASIL等级** | QM/A/B/C/D（功能安全相关） |
| **测试环境** | MIL/SIL/HIL/实车 |
| **自动化类型** | 手动/自动化/半自动化 |
