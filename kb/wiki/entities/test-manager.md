# 测试经理（TM）

**测试经理**（Test Manager，TM）是软件测试流程中负责监督和控制测试进度与质量的角色。

## 核心职责

- **进度监督**：跟踪测试任务完成情况，确保按计划推进
- **质量监督**：评估测试效果，把控缺陷收敛趋势
- **风险控制**：识别和应对测试过程中的风险
- **资源协调**：调配测试人员、设备和环境
- **测试报告**：审核测试报告，向项目组汇报测试结论
