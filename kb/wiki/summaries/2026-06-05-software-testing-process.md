# 软件测试流程概述

软件测试流程将测试活动划分为 **7 个阶段**，从计划到结束形成闭环：

1. **测试计划（5W1H）** — What/Who/Where/When/Why/How
2. **测试监督与控制** — TM负责，贯穿全程
3. **测试分析** → 输出测试条件（可追溯）
4. **测试设计** → 输出测试用例
5. **测试实施** → 输出测试规程（环境+分组+优先级）
6. **测试执行** → 输出Bug单、测试日志、检查表
7. **测试结束** → 输出测试报告、经验总结

**关键原则**：可追溯性（测试条件↔需求）、渐进细化、监督闭环。
